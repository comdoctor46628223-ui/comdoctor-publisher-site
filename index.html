WHAT IT DOES

게시 준비에 필요한 핵심 기능

로컬 우선

계정 설정, 예약, 미디어와 토큰을 사용자의 컴퓨터에 저장합니다.

여러 계정 예약

플랫폼과 계정을 선택해 각 계정의 영상 전송 시점을 관리합니다.

공식 API 연결

브라우저 쿠키나 비공식 자동화를 사용하지 않고 OAuth로 연결합니다.

TIKTOK UPLOAD API

공개 여부는 사용자가 직접 결정합니다

앱은 사용자가 선택한 MP4 영상 한 개를 TikTok 공식 Upload API로 TikTok 받은 편지함에 전송합니다. 앱이 자동 공개하거나 공개 범위를 대신 선택하지 않습니다.

  1. 1컴닥터 퍼블리셔에서 TikTok 계정을 OAuth로 연결합니다.
  2. 2전송할 MP4 영상 한 개와 전송 시점을 선택합니다.
  3. 3TikTok 앱 알림을 열어 제목과 공개 범위를 확인합니다.
  4. 4사용자가 TikTok 앱의 게시 버튼을 눌러 완료합니다.

INSTAGRAM CONTENT PUBLISHING API

프로 계정에 공식 API로 게시합니다

Instagram 비즈니스 로그인을 통해 사용자가 관리하는 프로 계정을 연결하고, 선택한 이미지나 MP4 영상을 Instagram 공식 API로 게시합니다. Facebook 페이지 연결은 필요하지 않습니다.

  1. 1Instagram 계정을 비즈니스 또는 크리에이터 계정으로 전환합니다.
  2. 2컴닥터 퍼블리셔에서 Instagram 공식 로그인을 완료합니다.
  3. 3게시할 미디어, 캡션과 전송 시점을 선택합니다.
  4. 4앱이 공식 Content Publishing API로 계정에 게시합니다.

macOS 설치 방법

  1. 다운로드한 ZIP을 열고 “컴닥터 퍼블리셔 독립실행” 앱을 응용 프로그램 폴더로 옮깁니다.
  2. Apple Developer ID 공증 배포본이 아니므로 최초 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 “확인 없이 열기”를 선택합니다.
  3. 앱의 API 설정 화면에서 본인이 등록한 공식 플랫폼 개발자 앱 값을 입력합니다.

FAQ

자주 묻는 질문

TikTok에 바로 공개되나요?

아니요. 영상은 TikTok 받은 편지함으로 전송되며 사용자가 TikTok 앱에서 공개 범위를 선택하고 게시해야 합니다.

로그인 정보가 외부 서버에 저장되나요?

앱 운영자가 별도 클라우드 계정 서버를 제공하지 않습니다. 앱 설정과 OAuth 토큰은 사용자의 로컬 앱 데이터 폴더에 저장됩니다.

Instagram에 Facebook 페이지 연결이 필요한가요?

아니요. 컴닥터 퍼블리셔는 Instagram 비즈니스 로그인 방식을 사용하므로 프로 Instagram 계정으로 직접 연결합니다.

계정 연결을 해제할 수 있나요?

앱에서 연결을 삭제하고 TikTok 또는 Instagram 계정 설정에서 앱 권한을 철회할 수 있습니다. 자세한 내용은 데이터 삭제 안내를 확인하세요.
