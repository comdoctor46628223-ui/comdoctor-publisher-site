컴닥터 퍼블리셔

PRIVACY POLICY

개인정보처리방침

시행일: 2026년 8월 11일

컴닥터 퍼블리셔 운영자(이하 “운영자”)는 무료 로컬 데스크톱 앱인 컴닥터 퍼블리셔를 제공합니다. 본 방침은 앱이 처리하는 정보와 사용자의 선택권을 설명합니다.

1. 처리하는 정보

  • TikTok OAuth 연결 과정에서 제공되는 기본 프로필 식별 정보
  • 공식 API 호출에 필요한 액세스 토큰과 갱신 토큰
  • 사용자가 선택한 MP4 영상, 예약 시각 및 전송 상태
  • 오류 해결에 사용자가 자발적으로 제공하는 문의 내용

2. 이용 목적

계정 연결 확인, 사용자가 요청한 영상 전송, 예약 작업 수행, 오류 진단과 고객 지원에만 이용합니다. 광고 프로파일링이나 개인정보 판매에 이용하지 않습니다.

3. 저장 위치와 보유 기간

앱 설정, 토큰, 예약과 미디어는 원칙적으로 사용자의 컴퓨터 내 앱 데이터 폴더에 저장됩니다. 사용자가 연결 또는 로컬 앱 데이터를 삭제할 때까지 보관됩니다. 운영자는 별도의 컴닥터 퍼블리셔 클라우드 계정 데이터베이스를 운영하지 않습니다.

4. 제3자 제공과 국외 처리

사용자가 TikTok 전송을 실행하면 기본 프로필 확인 정보, 인증 토큰 및 선택한 영상이 TikTok의 공식 API로 전달됩니다. TikTok의 처리는 TikTok의 개인정보처리방침과 계정 설정이 적용됩니다. 그 밖에 정보를 판매하거나 임의의 제3자에게 제공하지 않습니다.

5. 보안

OAuth 연결에는 요청별 보안 state와 PKCE를 사용하고, 콜백은 사용자 컴퓨터의 loopback 주소로 제한합니다. 사용자는 운영체제 계정과 디스크를 안전하게 보호해야 합니다.

6. 사용자의 권리와 삭제

사용자는 언제든 앱에서 TikTok 연결을 삭제하고 TikTok 설정에서 권한을 철회하며 로컬 데이터를 삭제할 수 있습니다. 단계별 방법은 데이터 삭제 안내에 설명되어 있습니다.

7. 문의

개인정보 관련 문의는 지원 페이지의 공개 문의 채널을 이용해 주세요. 토큰, 비밀번호, 영상 원본 또는 민감한 개인정보는 공개 문의에 첨부하지 마세요.

8. 방침 변경

처리 방식이 변경되면 이 페이지의 시행일과 내용을 갱신합니다. 중요한 변경은 사이트 또는 앱 안내를 통해 알립니다.
