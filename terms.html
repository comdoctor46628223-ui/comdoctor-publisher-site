컴닥터 퍼블리셔

TERMS OF USE

이용약관

시행일: 2026년 8월 11일

본 약관은 컴닥터 퍼블리셔 운영자(이하 “운영자”)가 제공하는 무료 로컬 데스크톱 앱의 이용 조건을 정합니다.

1. 서비스

앱은 사용자가 소유하거나 적법하게 관리하는 소셜 미디어 계정을 OAuth로 연결하고, 사용자가 선택한 미디어를 공식 API를 통해 전송하도록 돕습니다. TikTok 영상은 받은 편지함으로 전송되며 사용자가 TikTok 앱에서 최종 내용을 확인하고 게시합니다. Instagram 콘텐츠는 사용자가 연결한 프로 계정에 Instagram 공식 API로 게시됩니다.

2. 사용자의 책임

  • 자신이 연결 권한을 가진 계정만 사용해야 합니다.
  • 업로드할 콘텐츠의 저작권, 초상권 및 관련 법령을 준수해야 합니다.
  • TikTok과 Instagram을 포함한 각 플랫폼의 약관과 커뮤니티 가이드라인을 준수해야 합니다.
  • 게시 전 제목, 공개 범위, 상업성 표시와 콘텐츠를 직접 확인해야 합니다.

3. 금지 행위

무단 계정 접근, 스팸, 기만적 게시, 불법 콘텐츠 전송, 보안 기능 우회, 공식 API 제한 회피 또는 타인의 권리를 침해하는 용도로 앱을 사용할 수 없습니다.

4. 비용과 외부 서비스

운영자는 컴닥터 퍼블리셔 월 구독료를 부과하지 않습니다. 인터넷, 운영체제 또는 외부 플랫폼이 별도로 부과하는 비용과 정책은 해당 제공자의 조건을 따릅니다.

5. 가용성과 책임 제한

외부 플랫폼의 API 변경, 심사 상태, 계정 제한, 네트워크 또는 사용자 컴퓨터 환경에 따라 기능이 중단될 수 있습니다. 사용자는 예약 결과와 실제 게시 상태를 플랫폼에서 확인해야 하며 중요한 미디어와 설정을 별도로 백업해야 합니다.

6. 이용 종료

사용자는 앱의 계정 연결과 로컬 데이터를 삭제하여 언제든 이용을 종료할 수 있습니다. 운영자는 불법 또는 악용 신고가 확인되는 경우 지원 제공을 제한할 수 있습니다.

7. 문의와 변경

문의는 지원 페이지에서 접수합니다. 약관이 변경되면 시행일과 변경 내용을 이 페이지에 반영합니다.
